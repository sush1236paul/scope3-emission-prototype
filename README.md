# Scope-3 Carbon Tracker (Hackathon MVP)

This project is a hackathon-ready MVP that estimates Scope-3 supply-chain carbon emissions
from unstructured supplier documents using OCR, NLP, and deterministic calculations.

## Features
- Upload supplier invoices and documents
- Extract activity data (mock NLP)
- Estimate emissions using standard factors
- Full audit trail (evidence-based)
- Dashboard with supplier comparison
- Upload history and batch comparison

## Tech Stack
- Backend: FastAPI (Python)
- Frontend: Streamlit
- Database: SQLite / Session State
- AI: LLM-based extraction (mocked for demo)
